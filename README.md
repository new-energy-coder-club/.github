## 🏛 关于我们

NEC（New Energy Coder Club）是一个连接、启发和赋能新能源领域开发者与爱好者的开源工程社区。我们围绕：

- 🤖 **机器人竞赛** — CURC / RoboCon 系列赛事的备赛资料与开源工程
- ⚡ **新能源嵌入式** — 电控、电机驱动、光伏储能等实战项目
- 📖 **知识沉淀** — 学习路线、技术文档、赛事规则整合（LeggedWiki 等）
- 🤝 **开源协作** — 模板化项目结构、贡献者成长体系
